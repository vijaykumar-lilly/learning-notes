      $ cp .env.example .env
      $ nano .env

      $ node scripts/test-api-connection.js
      ✅ Success! Connected to Claude API

┌─────────────────────────────────────────────────────────────────────────┐
│  TROUBLESHOOTING                                                        │
└─────────────────────────────────────────────────────────────────────────┘

  ❌ "API key not found"
     → Check: cat .env
     → Verify: ANTHROPIC_API_KEY=sk-ant-api03-...

  ❌ "Invalid API key"
     → Regenerate at console.anthropic.com
     → Check for typos/spaces

  ❌ "Rate limit exceeded"
     → Wait 60 seconds
     → Check plan limits

  ❌ Build fails
     → npm run build 2>&1 | grep Error
     → rm -rf .next && npm run build
